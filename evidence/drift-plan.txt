## Who is right: the file or the account?

The file (the Terraform configuration code) is right.

In Infrastructure as Code (IaC) and GitOps practices, version-controlled code is the single declared source of truth for all infrastructure. Any changes made directly via the AWS CLI or cloud console represent configuration drift—untracked, unreviewed mutations that bypass peer review, CI/CD validation, and audit trails.

When drift occurs, Terraform's plan highlights the discrepancy between reality and declared intent. Unless the live change was an urgent manual fix that the engineering team explicitly decided to adopt and backport into the `.tf` source files, running `terraform apply` will revert the out-of-band change and restore the infrastructure to the canonical state specified in the configuration.
